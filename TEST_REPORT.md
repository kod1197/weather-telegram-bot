# Отчет по тестированию weather.py

Дата: 2026-07-03

## Что проверено

- Корректная загрузка JSON из API и кодирование параметров URL.
- Обработка HTTP-ошибок с сообщением от API.
- Обработка сетевых ошибок.
- Повторный запрос при временной сетевой ошибке.
- Поиск города и ошибка для отсутствующего города.
- Валидация названия города: текстовые названия принимаются, числа и значения с цифрами отклоняются.
- Формирование запроса текущей погоды по координатам.
- Формирование запроса дневной сводки по координатам.
- Человекочитаемый вывод погоды, включая описание weather code.
- Обычная погода не выводит техническую строку времени из API.
- Скорость ветра в обычной погоде и `/today` выводится единообразно в `км/ч`.
- Форматирование сводки на день с дневным минимумом, максимумом, осадками, ветром и советом.
- Форматирование сводки на день при отсутствии optional daily-полей.
- Выбор приветствия для сводки по времени: утро, день, вечер, ночь.
- Эмодзи в строках сводки `/today`.
- Вариативные советы для похожих погодных условий.
- Ошибка при неожиданном формате ответа прогноза.
- Основные CLI-сценарии: город передан аргументом, город не указан, вместо города передано число.
- Telegram-бот: команды `/start` и неизвестные команды.
- Telegram-бот: ответ по названию города и ошибка для числового ввода.
- Telegram-бот: отправка ответа в правильный `chat.id`.
- Telegram-бот: обработка успешных, ошибочных и сетевых ответов Telegram API.
- Telegram-бот: эмодзи в погодном ответе.
- Telegram-бот: сохранение города по умолчанию в SQLite.
- Telegram-бот: команды `/setcity`, `/city`, `/weather`.
- Telegram-бот: команда `/today` с городом по умолчанию и с аргументом.
- Telegram-бот: кнопка `📅 Сегодня`.
- Telegram-бот: приветствие в сводке выбирается по timezone города.
- Telegram-бот: подготовленные поля для будущей автодоставки погоды.
- Telegram-бот: регистрация меню команд через `setMyCommands`.
- Telegram-бот: меню команд настраивается до старта чтения updates.
- Telegram-бот: постоянная reply-клавиатура в `reply_markup`.
- Telegram-бот: сценарий настройки города через кнопку и следующее сообщение.
- Telegram-бот: отдельная таблица `user_state` для коротких диалогов.
- Telegram-бот: настройка ежедневной отправки через `/settime` и кнопку.
- Telegram-бот: отключение ежедневной отправки.
- Telegram-бот: поиск due-рассылок по timezone сохраненного города.
- Telegram-бот: защита от повторной отправки в тот же локальный день.
- Telegram-бот: отправка дневной due-сводки и запись `last_notification_date`.
- Telegram-бот: дружелюбный текст при ошибке ежедневной сводки без технических `_ssl` деталей.
- Telegram-бот: ошибка ежедневной сводки не повторяется каждые 30 секунд.
- Telegram-бот: обновление отсутствующего timezone при настройке рассылки.
- Telegram-бот: конфигурация админов через `ADMIN_USERNAMES`.
- Telegram-бот: отказ в админ-командах для неадминов.
- Telegram-бот: админ-команды `/admin`, `/admin_metrics`, `/admin_users`.
- Telegram-бот: запись Telegram-профиля пользователя в таблицу `bot_users`.
- Telegram-бот: обновление существующего профиля пользователя.
- Telegram-бот: метрики по пользователям, городам, рассылкам и незавершенным диалогам.
- Telegram-бот: список последних пользователей с городом и статусом рассылки.
- Telegram-бот: админ-команды не попадают в общее меню команд.
- Telegram-бот: отдельная админская reply-клавиатура для администратора.

- Telegram-бот: кнопки админки открывают метрики, пользователей, бан и бан-лист.

## Примечания

Тесты не делают реальные сетевые запросы. Внешние вызовы замоканы, поэтому набор быстрый,
стабильный и не зависит от доступности Open-Meteo во время запуска.

На сервере тесты также были запущены из `/opt/weather-bot` и прошли успешно:

```text
Ran 89 tests in 0.258s

OK
```
